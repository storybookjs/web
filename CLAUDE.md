# Project instructions

For any UI component work — building or modifying components, writing or updating stories, or otherwise iterating on UI — use the matching MCP server for the area you're working in:

- `apps/frontpage` → `storybook-frontpage` MCP server
- `packages/ui` → `storybook-ui` MCP server

The user runs the Storybooks themselves, which exposes these MCP servers. If the expected server isn't available when you need it, ask the user to start the relevant Storybook rather than proceeding without it.
